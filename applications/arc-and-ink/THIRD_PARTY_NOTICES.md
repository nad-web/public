# Arc & Ink credits

Developed and designed by **Noorullah Adel · 2026**. The MIT license in this folder covers the original game code, level text, illustrations, icons, synthesized sound design and documentation.

Arc & Ink is an independent straightedge-and-compass game. Euclidea by Horis International Limited was a genre reference. All puzzles were written for this game around classical constructions. The interface, code, artwork, sounds and explanations were created for this release. No Euclidea assets, code or branding are included.

The app uses browser APIs and system fonts. It bundles no third-party libraries, fonts, music or recordings.
