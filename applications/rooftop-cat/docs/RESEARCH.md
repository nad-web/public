# Platform research

Reviewed **7 November 2026**. Implementation and original artwork by **Noorullah Adel**.

| Topic                            | Primary source                                                                                                                                                                                                                   | Decision                                                                                                      |
| -------------------------------- | -------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------- |
| iPhone Home Screen installation  | [Apple iPhone guide](https://support.apple.com/guide/iphone/iphea86e5236/ios), [WebKit Safari 26](https://webkit.org/blog/17333/webkit-features-in-safari-26-0/)                                                                 | Explain Share, Add to Home Screen, and Open as Web App where offered.                                         |
| Progressive installation support | [MDN installability](https://developer.mozilla.org/en-US/docs/Web/Progressive_web_apps/Guides/Making_PWAs_installable), [beforeinstallprompt](https://developer.mozilla.org/en-US/docs/Web/API/Window/beforeinstallprompt_event) | Actual native prompt only when supported; otherwise manual guidance and tab gameplay.                         |
| Gesture-based audio              | [MDN Web Audio practices](https://developer.mozilla.org/en-US/docs/Web/API/Web_Audio_API/Best_practices)                                                                                                                         | Initially muted, explicitly unlocked, locally synthesized chimes with immediate muting and a silent fallback. |
| Background behavior              | [MDN Page Visibility](https://developer.mozilla.org/en-US/docs/Web/API/Page_Visibility_API)                                                                                                                                      | Pause while hidden; explicit resume prevents an unseen lost life.                                             |
| Touch and keyboard               | [W3C Pointer Events](https://www.w3.org/TR/pointerevents/), [Apple games guidance](https://developer.apple.com/design/human-interface-guidelines/designing-for-games/)                                                           | Primary pointer input, a large Jump button, keyboard alternatives and touch-action limited to the game area.  |
| Offline lifecycle                | [MDN using service workers](https://developer.mozilla.org/en-US/docs/Web/API/Service_Worker_API/Using_Service_Workers)                                                                                                           | Own folder scope, complete precache, readiness checks, repair and intentional updates.                        |
| Matching release assets          | [MDN Request.integrity](https://developer.mozilla.org/en-US/docs/Web/API/Request/integrity)                                                                                                                                      | Generate SHA-256 integrity values and a revision from the actual runtime files.                               |

Browser APIs and installation menus are feature-detected. These references informed original implementation; their text, illustrations and source examples are not redistributed. Offline files remain available while browser storage is retained. Physical-device tests and actual HTTPS installation checks are distinguished from desktop frame and automated worker tests in VALIDATION.md.
