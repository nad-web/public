## iPhone and iPad

1. Open the game's HTTPS link in **Safari** while online.
2. Tap **Share**: the square with an upward arrow, or **Page Menu → Share**, depending on Safari's layout.
3. Choose **Add to Home Screen**. If missing, look under **Edit Actions**. If another browser does not offer it, open the link in Safari.
4. Leave **Open as Web App** enabled if offered, then tap **Add**.
5. Open the new **Rooftop Cat** icon while still online. An installed app can have separate storage from a browser tab.
6. Wait for **Ready for offline adventures** below the game.
7. Close the game, turn on Airplane Mode and reopen its icon. Start a run and try jumping and fish sounds. This verifies your device's offline setup.

Current third-party iPhone browsers may also offer Add to Home Screen through Share. The in-game Install button opens instructions; it cannot force a native iOS installation prompt. Menu names depend on the browser and OS version.

## Android

Use the browser menu's **Install app** or **Add to Home screen** action. If a native in-game install button appears, it can open the browser's actual installation prompt. Some browsers create a shortcut instead. Open the new icon online and wait for offline readiness before disconnecting.

## Desktop

| Browser                   | Installation route                                                                                               |
| ------------------------- | ---------------------------------------------------------------------------------------------------------------- |
| Chrome / Edge             | Address-bar install icon or the browser menu's app-install action; use the in-game native prompt when available. |
| Safari on supported macOS | File → Add to Dock.                                                                                              |
| Other browsers            | Play in a normal tab; bookmark the game or use the browser's website shortcut where available.                   |

Installation is optional. Gameplay and app-installation support are distinct; this project does not claim that every browser offers the same PWA interface.

## Sound and updates

Sound starts off. Use the speaker button to enable gentle fish chimes; a user gesture is required to unlock audio. Device volume/mute controls and browser policies still apply. The game remains playable silently if Web Audio is unavailable.

After each complete first download, the game verifies all core cache entries before reporting readiness. Storage pressure, private browsing, blocked storage or clearing website data can remove or prevent offline files. Use **Try again** online to check and repair. **Update game** saves the latest score snapshot, pauses, then reloads an explicitly offered new release. Avoid clearing all origin data merely to retry: other apps may share that origin.

For missing pages, check the repository workflow completed successfully, index.html is directly inside applications/rooftop-cat/, and every file was uploaded. Use the published HTTPS URL rather than a GitHub source-tree or downloaded file:// URL.
